# 坦克大战 (Tank Battle)

一个使用 HTML5 Canvas 和原生 JavaScript 开发的经典坦克大战游戏。

## 在线试玩

直接在浏览器中打开 `index.html` 即可开始游戏。

## 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格键` | 发射炮弹 |
| `P` | 暂停游戏 |

## 游戏特性

- 🎮 经典坦克大战玩法
- 🤖 智能敌人 AI，会追踪玩家
- 🧱 随机生成的地图，包含砖墙和钢墙
- 💥 炮弹爆炸粒子效果
- 📈 关卡递进系统，难度逐渐增加
- ❤️ 生命值系统

## 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- 无外部依赖

## 本地运行

```bash
# 克隆仓库
git clone <repository-url>

# 进入目录
cd tank-battle

# 用浏览器打开
open index.html
```

或者直接使用本地服务器：

```bash
npx serve .
```
