# 坦克大战 - 增强版 (Tank Battle Enhanced)

一个使用 HTML5 Canvas 和原生 JavaScript 开发的经典坦克大战游戏，支持单人和双人合作模式。

## 🎮 在线试玩

直接在浏览器中打开 `index.html` 即可开始游戏，或开启 GitHub Pages 在线游玩。

## 🎯 操作说明

### 单人模式

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格键` | 发射炮弹 |

### 双人模式

| 玩家 | 移动 | 射击 |
|------|------|------|
| **玩家1** (绿色) | `W` `A` `S` `D` | `空格键` |
| **玩家2** (蓝色) | `↑` `↓` `←` `→` | `回车键` |

### 通用按键

| 按键 | 功能 |
|------|------|
| `P` | 暂停 / 继续 |
| `M` | 切换音效静音 |

## ✨ 游戏特性

### 核心玩法
- 🎮 经典坦克大战玩法，单人或双人合作
- 🤖 智能敌人 AI，自动追踪最近的玩家
- 🧱 随机生成的地图，包含砖墙（可破坏）和钢墙（不可破坏）
- 💥 炮弹爆炸粒子效果
- 📈 关卡递进系统，难度逐渐增加
- ❤️ 生命值系统，阵亡后可在本关复活

### 道具系统
击杀敌人有概率掉落道具：

| 道具 | 图标 | 效果 |
|------|------|------|
| 生命值 | ❤️ 红色 | 生命 +1（上限5） |
| 护盾 | 🛡️ 蓝色 | 5秒无敌 |
| 穿甲弹 | 🔥 金色 | 10秒内子弹穿透钢墙 |
| 加速 | ⚡ 绿色 | 移动速度 ×1.8 |
| 核弹 | 💥 橙色 | 消灭全屏所有敌人 |

### 其他特性
- 🔊 完整音效系统（射击、爆炸、道具、核弹、游戏结束）
- 🔇 音效/背景音乐独立开关
- ⚡ 连击系统（连续击杀获得额外加分）
- 🛡️ 出生2秒无敌保护
- 🚧 坦克碰撞检测（不会互相穿透）

## 🛠️ 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+ Class)
- Web Audio API（合成音效，无外部资源依赖）
- 零外部依赖，单文件运行

## 🚀 本地运行

```bash
# 克隆仓库
git clone https://github.com/woleyiLI/tank-battle.git

# 进入目录
cd tank-battle

# 用浏览器打开
open index.html
```

或使用本地服务器：

```bash
npx serve .
```
